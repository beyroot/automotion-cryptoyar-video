# کریپتویار · اتوماسیون موشن روزانه

هر روز دو ویدیوی عمودی ۳۰ تا ۴۰ ثانیه‌ای (ساعت ۱۹ و ۲۲ تهران) می‌سازد و در یوتوب (Shorts) و اینستاگرام (Reels) منتشر می‌کند.

## چه چیزی کجاست
| مسیر | کار |
| --- | --- |
| `content/episodes.json` | بانک اپیزودهای آموزشی (متن، صحنه، کپشن، متن گوینده `vo`) |
| `assets/vo/` | صدای گوینده برای اپیزودهای گویندگی‌شده (`src/voice.mjs`) |
| `template/` | قالب موشن بر پایهٔ متد «storytime» خودِ برند (کپشن بالا، کارت وسط، پیل برند پایین) + لوگو موشن |
| `assets/brand/` | لوگو و وردمارک اصلی کریپتویار (از `insta-motion/public/brand`) |
| `assets/audio/music-viral.mp3` | موسیقی اورجینال برند (همان ترک `insta-motion`) |
| `src/daily.mjs` | اجرای روزانه: انتخاب اپیزود، رندر، انتشار |
| `src/pulse.mjs` | اپیزود زندهٔ «نبض بازار» با قیمت واقعی از CoinGecko (جمعه‌ها) |
| `.github/workflows/daily.yml` | زمان‌بندی: هر روز ۱۹:۰۰ و ۲۲:۰۰ تهران روی GitHub Actions، بعد ذخیرهٔ کلیپ در ریپو |
| `clips/YYYY-MM-DD/` | پکیج هر روز (ویدیو، کاور، متادیتا). از `startDate` به بعد، هر روز یک پوشه |
| `config.json` | نام برند، هندل، تگ‌ها، تاریخ شروع، روزهای نبض بازار |

## اجرای محلی (ویندوز)
1. Node 22 و ffmpeg نصب باشد: `winget install OpenJS.NodeJS Gyan.FFmpeg`
2. `npm install`
3. `npm run validate` : همهٔ اپیزودها را از نظر طول و جا شدن در قاب چک می‌کند.
4. `npm run preview` : ویدیوی امروز را بدون انتشار در `clips/<تاریخ امروز>/` می‌سازد.
5. `npm run render ep07` : یک اپیزود مشخص، فقط در `out/` (وارد ریپو نمی‌شود).

کروم نصب‌شده روی سیستم استفاده می‌شود. اگر پیدا نشد، `CHROME_PATH` را تنظیم کنید.

## راه‌اندازی انتشار خودکار
1. این پوشه را در یک ریپوی **خصوصی** گیت‌هاب push کنید.
2. در Settings → Secrets and variables → Actions این پنج راز را بسازید:
   `YT_CLIENT_ID`، `YT_CLIENT_SECRET`، `YT_REFRESH_TOKEN`، `IG_USER_ID`، `IG_ACCESS_TOKEN`
3. در تب Actions یک بار دستی اجرا کنید (Run workflow، با `publish=false`). ویدیو، کاور و متادیتا در `clips/<تاریخ>/` روی همین ریپو کامیت می‌شود.
4. `startDate` را در `config.json` روی روز شروع بگذارید.

### یوتوب
1. در Google Cloud یک پروژه بسازید و YouTube Data API v3 را فعال کنید.
2. یک OAuth client از نوع Desktop app بسازید.
3. محلی اجرا کنید: `npm run yt-auth` و با اکانت کانال وارد شوید. خروجی، `YT_REFRESH_TOKEN` است.
4. **مهم:** تا وقتی پروژهٔ API ممیزی یوتوب (API Compliance Audit) را نگذرانده، هر ویدیویی که با API آپلود شود «خصوصی» قفل می‌شود. فرم ممیزی را همان اول بفرستید. تا تأیید آن، فایل‌های `clips/<تاریخ>/` را دستی در YouTube Studio آپلود و زمان‌بندی کنید (هفته‌ای یک نشست برای ۷ ویدیو).

### اینستاگرام
1. اکانت اینستاگرام باید Professional (Business یا Creator) و به یک صفحهٔ فیس‌بوک وصل باشد.
2. در Meta for Developers یک اپ با Facebook Login for Business بسازید و مجوزهای `instagram_basic` و `instagram_content_publish` را بگیرید.
3. `IG_USER_ID` و یک توکن بلندمدت را در رازها بگذارید. توکن منقضی می‌شود؛ قبل از انقضا تمدیدش کنید.

## اضافه کردن اپیزود
یک آبجکت به `content/episodes.json` اضافه کنید. انواع صحنه:
`hook`، `define`، `bullets`، `number`، `bars`، `versus`، `chart`، `chat`، `takeaway`. دو صحنهٔ پایانی (CTA کامنتی و لوگو موشن با سلب مسئولیت) خودکار اضافه می‌شوند.
متن بین دو ستاره `*این‌طوری*` طلایی می‌شود. بعد از هر تغییر `npm run validate` بزنید.

## گویندگی (Voice studio)
اپیزودی که برای صحنه‌هایش فیلد `vo` دارد و فایل صدایش در `assets/vo/<id>/sNN.m4a` هست، **با گوینده** رندر می‌شود؛ بقیه مثل قبل فقط موسیقی دارند.
- صدا: استودیوی صدای Higgsfield، مدل `elevenlabs_v4`، گوینده **Kevin** (لحن مجری خبر، پرانرژی)، `stability: 0.3`. تنظیماتش در `config.json` ← `voice` است.
  چون GitHub Actions به این استودیو دسترسی ندارد، صدا در یک نشست Claude ساخته و در ریپو کامیت می‌شود؛ بعد اجرای روزانه خودش آن را برمی‌دارد.
- `node src/voice.mjs plan` : خط‌هایی که هنوز صدا ندارند (شامل CTA و لوگوی پایانی مشترک در `assets/vo/_shared/`).
- `node src/voice.mjs process raw.mp3 assets/vo/ep19/s00.m4a` : حذف سکوت، سرعت ۱.۱۵، ‏EQ و کمپرسور، بلندی ‎-15 LUFS.
- هر صحنه به‌اندازهٔ صدایش کش می‌آید، ردیف‌های لیست همزمان با گوینده ظاهر می‌شوند، موسیقی زیر صدا پایین می‌آید (sidechain)،
  افکت‌های whoosh/sparkle (‏`assets/sfx`، مجوز CC0 و Pixabay) آرام زیر صدا می‌نشینند و خروجی نهایی ‎-14 LUFS است.
- متن `vo` محاوره‌ای و کوتاه بنویسید، عددها با حروف («یک درصد»، «بیست‌وچهار ساعته»). بعد از ساخت، هر خط با Whisper چک شود.
- صحنهٔ جدید `chat`: نمایش گفت‌وگو با ربات تلگرام برند (`msgs: [{from: "me"|"bot", text, rows?}]`).

## قواعد محتوا
- آموزشی است، نه سیگنال. هیچ وعدهٔ سودی در متن‌ها نیست و سلب مسئولیت در پایان هر ویدیو می‌آید.
- نمودارهای آموزشی برچسب «نمودار نمایشی» دارند. عدد واقعی بازار فقط در «نبض بازار» و با ذکر منبع می‌آید.
- پایان هر ویدیو: CTA کامنتی («بنویس تحلیل») و بعد لوگو موشن. کلمهٔ کلیدی در `config.json` ← `brand.keyword` است.
- رنگ‌ها، کارت‌ها و چیدمان از `insta-motion/src/story-kit.tsx` و لوگو موشن از `launch-film/src/kit.tsx` گرفته شده تا با ریل‌های دستی یکدست باشد.
